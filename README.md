## Requirements

- Visual Studio 2022 / 2026（勾选 C++ 开发）
- Vulkan SDK 1.4.341.1 —— https://vulkan.lunarg.com/sdk/home

---

## Setup / Build

### 1️⃣ Clone项目

```bash
git clone https://github.com/fl0a1e/easy_vulkan.git
cd easy_vulkan
```

### 2️⃣ 打开项目

用 VS 打开 `.sln` 文件，运行即可

### 3️⃣ 编译运行

- 选择 `Debug` / `Release`
- 点击运行（F5）

---

## Notes

- 如果运行报错，请检查是否正确安装 Vulkan SDK
